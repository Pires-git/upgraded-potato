# upgraded-potato

## Meus Agentes / My Agents

### GitHub Copilot Coding Agent

O agente de codificação do GitHub Copilot está disponível neste repositório. Ele pode ser ativado ao atribuir uma issue ao Copilot ou ao mencionar `@copilot` em comentários de issues e pull requests.

The GitHub Copilot coding agent is available in this repository. It can be activated by assigning an issue to Copilot or by mentioning `@copilot` in issue and pull request comments.

**Capacidades / Capabilities:**
- Implementação de novas funcionalidades / Implement new features
- Correção de bugs / Fix bugs
- Refatoração de código / Refactor code
- Criação e atualização de testes / Create and update tests
- Revisão e análise de código / Code review and analysis

**Como usar / How to use:**
1. Crie uma issue descrevendo a tarefa / Create an issue describing the task
2. Atribua a issue ao `@Copilot` / Assign the issue to `@Copilot`
3. O agente abrirá um pull request com as mudanças / The agent will open a pull request with the changes

Para mais informações: [GitHub Copilot coding agent documentation](https://docs.github.com/en/copilot/using-github-copilot/using-copilot-coding-agent)
